# 3000s Prompt

Create a photorealistic year-3000 futuristic portrait using the uploaded photo as the identity reference.

Preserve the person’s face, facial features, skin tone, age, body proportions, natural facial structure, and overall identity exactly, so the person remains clearly recognizable as the same individual.

IMPORTANT: Use the uploaded photo primarily to preserve the person’s identity, natural facial characteristics, and natural hair/facial-hair presence.

Do not preserve the current hairstyle, haircut, facial-hair styling, clothing, accessories, pose, lighting, or background from the uploaded photo.

Completely reimagine everything else as if this photograph was taken in the year 3000.

The result must work naturally for both male and female subjects. Never force the same styling onto different people. Analyze each uploaded person’s individual appearance and choose the most suitable futuristic transformation.
